# Vercel Deployment Setup Guide

This guide walks you through deploying the What's Up Addis frontend to Vercel.

## Quick Start (Manual Deployment)

### 1. Push Code to GitHub

```bash
# If not already initialized
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/whats-up-addis.git
git push -u origin main
```

### 2. Deploy to Vercel (Web UI Method)

1. **Go to Vercel**: https://vercel.com/new
2. **Import Repository**:
   - Click "Add New..." → "Project"
   - Select your GitHub repository
   - Authorize Vercel to access your repository

3. **Configure Project**:
   - **Project Name**: `whats-up-addis` (or your preferred name)
   - **Framework Preset**: Next.js (auto-detected)
   - **Root Directory**: `apps/web`
   - **Build Command**: Leave as default or use: `pnpm build`
   - **Output Directory**: Leave as default (`.next`)
   - **Install Command**: `pnpm install`

4. **Environment Variables**:
   Add the following environment variable:

   ```
   Key: NEXT_PUBLIC_API_URL
   Value: http://localhost:3001 (temporary, will update after Railway deployment)
   ```

5. **Deploy**:
   - Click "Deploy"
   - Wait 2-3 minutes for the build
   - Your site will be live at `https://whats-up-addis-xxx.vercel.app`

## CI/CD Setup (Automatic Deployments with GitHub Actions)

For automatic deployments on every push to main branch:

### 1. Get Vercel Tokens

1. Go to **Vercel Dashboard** → **Settings** → **Tokens**
2. Click "Create Token"
3. Name it: `GitHub Actions CI/CD`
4. Select scope: Full Account
5. Copy the token (you'll only see it once)

### 2. Get Vercel Project IDs

Run these commands in your terminal:

```bash
# Install Vercel CLI
npm i -g vercel

# Login to Vercel
vercel login

# Link your project (run from project root)
vercel link

# Get project and org IDs
vercel project ls
```

Or get them from Vercel dashboard:

- **Project ID**: Project Settings → General → Project ID
- **Org ID**: Account Settings → General → Your ID

### 3. Add GitHub Secrets

Go to your GitHub repository → **Settings** → **Secrets and variables** → **Actions**

Add these secrets:

```
VERCEL_TOKEN=<your-vercel-token>
VERCEL_ORG_ID=<your-org-id>
VERCEL_PROJECT_ID=<your-project-id>
NEXT_PUBLIC_API_URL=https://your-api-url.up.railway.app (update later)
```

### 4. Enable GitHub Actions

The workflow file is already created at `.github/workflows/deploy.yml`

Push to main branch to trigger deployment:

```bash
git add .
git commit -m "Setup CI/CD"
git push origin main
```

## Update API URL After Railway Deployment

After deploying your backend to Railway:

1. Get your Railway API URL (e.g., `https://api.railway.app`)
2. Update in **Vercel**:
   - Go to Project Settings → Environment Variables
   - Update `NEXT_PUBLIC_API_URL` to your Railway URL
   - Redeploy: Deployments → ⋯ Menu → Redeploy

3. Update in **GitHub Secrets** (if using CI/CD):
   - Settings → Secrets → Actions
   - Update `NEXT_PUBLIC_API_URL`

## Custom Domain Setup

### 1. Add Domain to Vercel

1. Go to Project → Settings → Domains
2. Click "Add Domain"
3. Enter your domain (e.g., `whatsupaddis.com`)

### 2. Configure DNS

Add these DNS records at your domain registrar:

**For Root Domain** (whatsupaddis.com):

```
Type: A
Name: @
Value: 76.76.21.21
```

**For www Subdomain**:

```
Type: CNAME
Name: www
Value: cname.vercel-dns.com
```

**SSL Certificate**: Auto-generated by Vercel (usually within minutes)

## Troubleshooting

### Build Fails

**Error**: `Module not found: Can't resolve '@whats-up-addis/shared'`

**Solution**:

1. Ensure root directory is set correctly in Vercel
2. Check `transpilePackages` in `next.config.ts`
3. Clear cache and redeploy

**Error**: `Command "pnpm" not found`

**Solution**:

- Vercel auto-detects pnpm from `packageManager` field in `package.json`
- Verify it exists: `"packageManager": "pnpm@10.0.0"`

### API Connection Issues

**Error**: CORS errors or "Failed to fetch"

**Solution**:

1. Ensure `NEXT_PUBLIC_API_URL` is set correctly
2. Check Railway API has CORS enabled for Vercel domain
3. Verify API is running on Railway

### Slow Builds

**Solution**:

1. Enable pnpm caching (already configured in workflow)
2. Use Vercel's build cache (automatic)
3. Consider upgrading Vercel plan for faster builds
